# Chandru A — Portfolio

A static portfolio for Chandru A, Android Application Developer, based on his resume. Oversized type, a portrait-led hero, scrolling skill strip, project studies, and motion.

## Run

```sh
python3 -m http.server 8081 --bind 127.0.0.1
```

No dependencies or build step. Publish the contents of this directory on any static host. Relative asset paths support GitHub Pages repository subpaths.

## Edit

- `index.html`: biography, projects, skills, experience and contact links.
- `style.css`: responsive layout, CSS illustrations, motion and reduced-motion support.
- `script.js`: section reveals, project disclosures and email copying.
- `hero.css`, `hero.js`: hero layout, name intro, title transition, portrait tile assembly, pointer response and scroll dispersal. Reduced-motion and static image fallbacks are included.
- `assets/chandru-portrait.png`: transparent cutout of `assets/chandru.jpg`, used by the hero tile effect.
- `assets/Chandru_A_Resume.pdf`: resume, offered as a download.

Project illustrations are conceptual UI studies, not screenshots of the products. No live demo URLs were provided, so none are included. No contact form backend, analytics, external JavaScript, or tracking is included.
